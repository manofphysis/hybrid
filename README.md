# 📱 Cordova를 이용한 앱 개발 수업

## 🧭 수업 개요
Apache Cordova는 웹 기술(HTML, CSS, JavaScript)을 사용하여 모바일 앱을 개발할 수 있도록 해주는 오픈소스 프레임워크입니다. 이 수업에서는 Cordova를 활용해 크로스플랫폼 앱을 개발하는 방법을 학습합니다.

---

## 📚 수업 목표
- Cordova 개발 환경 설정
- 기본적인 Cordova 앱 구조 이해
- 플러그인을 활용한 네이티브 기능 연동
- Android/iOS 앱 빌드 및 테스트

---
